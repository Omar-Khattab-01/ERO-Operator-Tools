Support ERO Operator Tools

ERO Operator Tools is built and maintained independently by one person. I personally cover the hosting, database, and maintenance costs, and I work on updates, fixes, and new features in my free time.

If this site helps you check ERO paddles, saved work, today's board, or Line 1 map tools more easily, you can support the project with a voluntary contribution.

What support helps cover

  • Database and hosting fees needed to keep the tools available.
  • Ongoing maintenance, bug fixes, and reliability improvements.
  • New features for paddle lookup, saved work, today's board, and Line 1 map workflows.
  • Time spent keeping operator tools easier to use.

Free to use

Support is optional. The site remains free to use, and no feature is locked behind a contribution.

The goal is simply to make it easier to cover the real operating costs and continue improving the tools when time is available.

ERO Operator Tools is independent and is not affiliated with, endorsed by, or operated by OC Transpo or the City of Ottawa. Contributions are voluntary and are not tax-deductible charitable donations.
