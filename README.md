# ERO Operator Tools

For operators, made by an operator.

ERO Operator Tools is a web-based reference tool designed for OC Transpo Electric Rail Operators. It helps operators quickly look up paddle information, follow their work through the day, and keep commonly needed shift details close at hand.

## What It Does

- Look up ERO paddles by full paddle number or shorthand entry.
- View trip, block, report, start, clear, platform, and pay information in a clean operator-focused layout.
- See current trip status, upcoming work, breaks, splits, and clear times.
- Save regular work to an account for faster access.
- Keep a same-day paddle view for work being used during the current shift.
- Identify blocks that need a radio check.
- View a scheduled Line 1 reference mimic for operational awareness.
- Record and review shared LRV defect reports when account access is approved.

## Intended Use

ERO Operator Tools is intended as a practical reference companion for operators during day-to-day work. It is designed to make existing work information easier to access and review from a phone, tablet, or desktop browser.

This tool is an operator reference aid only. Operators must continue to follow official instructions, notices, procedures, and direction from supervision or control.

## Main Areas

- **Paddle Lookup**: Find a paddle and review its trips, timing, blocks, breaks, platform time, and pay time.
- **My Work**: Save regular paddles to an account for quick access.
- **Today's Paddle**: Keep the current shift's paddle available through the workday, including overnight work that clears after midnight.
- **Board**: Review current and upcoming work in a board-style view.
- **Line 1 Map**: View a scheduled Line 1 reference mimic linked back to paddle information.
- **LRV Defects**: Approved users can report defects and review shared defect history by LRV.

## Access

Core lookup and reference features are available through the site. Account-based features are used for saved work and restricted collaborative tools.

## Notes

The tool is built for clarity, speed, and practical use by operators. It does not replace official systems, documents, or operating instructions.
